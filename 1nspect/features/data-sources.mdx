Property Baseline (the panel on the Order Creation Wizard and the mobile inspection setup) pulls from authoritative public datasets. Each row on the panel cites its source. The data is read-only, always on, free, and credited where it appears. No subscriber configuration.

## The five sources

| Dataset | Source | What it tells you |
| --- | --- | --- |
| **Soil map unit, dominant component, shrink-swell potential** | USDA NRCS SSURGO | The soil type at the property's coordinates. Shrink-swell drives foundation movement risk. |
| **FEMA flood zone** | FEMA NFHL (National Flood Hazard Layer) | The property's flood zone (X, A, AE, V, etc.) |
| **EPA radon zone** | EPA Radon Zones | The county-level radon potential (Zone 1 highest, Zone 3 lowest) |
| **Termite pressure** | IRC R301.2(6) | The termite infestation probability map from the International Residential Code |
| **Climate zone + recommended attic insulation** | DOE/PNNL Climate Zones | The DOE climate zone (1A through 8), with the IECC's recommended attic insulation value for new construction in that zone |

## Where you see the data

- **Order Creation Wizard** — Property Baseline panel on the property step
- **Inspection Details** (web) — Property Baseline panel
- **Mobile inspection setup** — Property Baseline panel on the first screen when you tap into an assigned inspection
- **The AI narrative drafting** — the AI reads the baseline (especially shrink-swell, climate zone, flood zone) to calibrate its narratives

## The data is not shown to the client

Property Baseline is for the inspector and the office. It is not printed on the client's published report. The AI uses it internally to frame narratives but does not cite it verbatim.

## How current is the data?

Each dataset is kept current by its publisher on their own schedule:

- **NRCS SSURGO** is updated regularly as counties re-survey; county-level data can lag behind new development by months to years
- **FEMA NFHL** is updated as FEMA re-maps flood zones (every few years per community)
- **EPA Radon Zones** are stable; the EPA last updated the map in 1993 and treats it as a long-term classification
- **IRC R301.2(6)** is updated with each IRC code cycle
- **DOE/PNNL Climate Zones** are updated with each IECC cycle (roughly every 3 years)

## Construction-era materials

Separately from Site Conditions, the Property Baseline panel also shows **Construction-era materials**: materials typical for this build year and region (water supply piping, drain/waste/vent, cladding, roof covering, etc.) with a prevalence percentage and a severity score. This is a 1nspecT-maintained matrix, not a public dataset, derived from inspection-industry service-life guidance and historical construction practice.

## Rate limits

All five datasets are cached per address in your tenant, so repeated views of the same property don't re-query the sources. The first lookup for a new property pulls fresh; subsequent lookups serve the cached version.
