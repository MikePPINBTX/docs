All Invoices is the simplest report in the suite: a flat list of every invoice generated in the period, with a PDF download on every row and a one-click CSV export of the full list. Built for bulk accounting handoff.

## Where to find it

**Reports** top-nav › the **All Invoices** card.

## Filters

| Filter | Options |
| --- | --- |
| Period | Date-range picker. |

## What the report shows

Stat grid at the top with totals for the period: invoice count, total billed, total paid, total outstanding.

Table below with one row per invoice:

- Invoice number
- Issue date
- Client name
- Property address
- Total amount
- Paid amount
- Balance due
- Status (paid, partial, unpaid, voided)
- Download icon (per row) — opens the PDF of that invoice in a new tab

## Export to CSV

Click the **CSV** button to export the full list. Column headers match the on-screen table.

## When each invoice is generated

Invoices are generated:

- When an agreement is signed (initial invoice with the quoted amount)
- When an order is edited with delta billing that changes the total (top-up invoice)
- When a service is added to a signed order (incremental invoice)
- Re-stamped PAID when payment lands

See [Payments setup](/1nspect/admin-operator/payments-and-contracts) for payment configuration.
