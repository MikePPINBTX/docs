The Repair Request Builder turns a published inspection report into a contractor-ready repair request. The buyer or buyer's agent (whoever opens the agent view of the report) ticks the deficiencies they want addressed. The AI drafts the request in plain, actionable language. The agent edits anything that needs tweaking and downloads a PDF. No separate AI credit cost — included on every plan.

## Where to find it

On the agent view of the report (`/report/[slug]/agent`). A **Repair Request** button at the top of the viewer opens the builder. The button label shows a count once findings have been ticked: _"Repair Request (3)"_ if three findings are selected.

## How the builder works

<Steps>
<Step title="Tick findings">
As the agent reads the report, each finding has an **Add to Repair Request** toggle. Ticking adds the finding to the builder's working set.
</Step>
<Step title="Open the builder">
Click the **Repair Request** button at the top of the viewer. The dialog opens with the ticked findings grouped by section and subsection.
</Step>
<Step title="Generate the draft">
Click **Generate Repair Request**. The AI reads the selected findings and drafts the request in a plain, actionable, contractor-ready voice. Each block corresponds to one finding and names the trade specialist appropriate for the work.
</Step>
<Step title="Edit">
Every block is editable. The agent can rewrite, add context, strike items, or add a cover note.
</Step>
<Step title="Download the PDF">
Click **Download Repair Request PDF**. The PDF is formatted for sending to a seller's agent, the seller, or a contractor to use for pricing.
</Step>
</Steps>

## Agent reminders in the builder

If no findings have been ticked when the agent opens the dialog, the empty state reads: _"Tick **Add to Repair Request** on any finding to build your list."_

## What's not in the request

- Pricing / cost estimates — the request is a scope document, not a bid
- Photos — the finding's photos stay in the report; the request links back to the report for reference
- Inspector contact details — the request is between the client/agent and the seller or contractor

## Cost

**Free.** The AI generation for the repair request is bundled on every plan. No AI credits are deducted. This is `repair-request` in the token service (`token.service.ts`) and sits in the Free Operations list.

## Who can build one

The builder is on the agent view by default. For clients who want to build their own repair request, the client view can also carry the builder depending on your settings. The default is agent view only.
