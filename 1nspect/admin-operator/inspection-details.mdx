Inspection Details is the per-order page. Open any order from the Inspections list and land here. All of the order's actions, data, inspections, communications and payment history live on this page.

## Where to find it

**Inspections** top-nav › click any order. URL pattern: `/inspections/[id]`.

## Page layout

- **Top header**: order number, client names, property address, status
- **Action buttons** (below header): Edit Order, Add Service, Cancel Order, and others covered in [Managing orders](/1nspect/workflows/managing-orders)
- **Left column**: Inspections in this Order (one row per phase for multi-phase orders)
- **Right column**: Order Summary + Order History cards

## Order Summary card

Three stats:

- **Total** — dollar order total
- **Paid** — amount received so far (green)
- **Balance due** — amount still owed (red if positive, green if 0)

## Order History card

Chronological log of events on this order: created, agreement sent, signed, payment received, edited, cancelled, published, delivered. Append-only.

## Inspections in this Order

One row per child inspection. Each row has:

- Inspection number
- Service type
- Scheduled date
- Status
- Assigned inspector
- Links to [Report Workspace](/1nspect/admin-operator/inspection-reviewer) for review and publish

For multi-phase orders, each phase appears as its own row.

## Action buttons (top of page)

| Action | What it does |
| --- | --- |
| **Edit Order** | Change clients, property, services, discounts, surcharges, detached structures. Triggers delta billing. See [Managing orders](/1nspect/workflows/managing-orders). |
| **Add Service** | Add a primary or ancillary service to a signed order without voiding the agreement. |
| **Resend Bundle** | Re-send the applicable agreements. Used after Add Service or when a client lost the original email. |
| **Cancel Order** | Full multi-select cancel: whole order, one phase, or one ancillary. Covered in [Managing orders](/1nspect/workflows/managing-orders). |
| **Mark as Paid** | Record a manual payment (Venmo, Zelle, Cash App, check). Opens the Mark Paid modal. |
| **Reschedule** | Move an inspection to a new date and time. |
| **Create Reinspection** | On the Overview tab for completed inspections. See [Reinspections](/1nspect/workflows/reinspections). |

## Communications log

Below the main content: every email that's been sent or scheduled for this order. Resend any individual email from here if needed.

## Haven toggle (per order)

If Haven is enabled at the tenant level (**Business Ops › Integrations**), a per-order **Send to Haven on publish** toggle appears. Defaults to on; uncheck for orders you don't want sent. See [Haven integration](/1nspect/features/haven-integration).
