Inspection Details is the per-order page. Open any order from the Inspections list and land here. All of the order's actions, data, inspections, communications and payment history live on this page.

## Where to find it

**Inspections** top-nav › click any order. URL pattern: `/inspections/[id]`.

## Page layout

- **Top header**: order number, client names, property address, status
- **Action buttons** (below header): Edit Order, Add Service, Cancel Order, and others covered in [Managing orders](/1nspect/workflows/managing-orders)
- **Tabs**: an order shows **Overview**, **Client & Realtor Info**, **Inspections** and **History**. A child inspection adds **Inspection Details**, **Reports** and **Communications**.
- The Report Workspace sits on the child inspection's **Reports** tab.

## Order Summary card

Three stats:

- **Total** — dollar order total
- **Paid** — amount received so far (green)
- **Balance Due** — amount still owed (red if positive, green if 0)

(The labels read Total Fees, Paid and Balance Due.)

## History

Both the order and each inspection have a **History** tab, newest first:

- **Inspection History** (on an inspection) shows that inspection's events.
- **Order History** (on the order) shows the order's own events plus every inspection's. Each row carries a chip: **Order**, or the inspection number and service. Click an inspection chip to open that inspection on its History tab. An extra **Inspection** filter narrows the list to All, Order or one inspection.

**Type filter** (both views): All, Status, Reports, Contracts, Financial, Comms, Notes. Each row's type shows as a chip, such as **REPORT PUBLISHED** or **COMMUNICATION SENT**.

What appears:

| Kind | Rows |
| --- | --- |
| Status | Status changes, rescheduled (old → new date), inspector assigned or changed, order created (web or mobile), order created from a quote, and *Finish & Draft from the mobile app: inspection completed and AI drafting started.* |
| Reports | Report published or republished (with the version), and report delivered (with the recipients) |
| Financial | Payments and each refund (amount, Stripe or how you returned it, reason, internal note) |
| Comms | Every email: **COMMUNICATION SENT** (with recipients, and any bounce), **COMMUNICATION SCHEDULED** (with the send time, Central), **COMMUNICATION FAILED** and **COMMUNICATION SKIPPED**. A delayed email appears once: its "scheduled" row is replaced when it sends. |
| Notes | Notes you add with **Add Note** (**Add Order Note** on the order, **Add Inspection Note** on an inspection) |

Every row shows who did it, *by* the signed-in user's name. Rows from before November 4, 2026 were not back-filled, so older orders show fewer events.

Per-structure panels (AI baseline, site conditions, era materials) appear on the inspection's view only.

## Inspections in this Order

One row per child inspection. Each row has:

- Inspection number
- Service type
- Scheduled date
- Status
- Assigned inspector
- Links to [Report Workspace](/1nspect/admin-operator/inspection-reviewer) for review and publish

For multi-phase orders, each phase appears as its own row.

## Action buttons (top of page)

| Action | What it does |
| --- | --- |
| **Edit Order** | Change clients, property, services, discounts, surcharges, detached structures. Recomputes billing and regenerates the invoice in place. See [Managing orders](/1nspect/workflows/managing-orders). |
| **Add Service** | Add a primary or ancillary service to a signed order without voiding the agreement. |
| **Resend Bundle** | Re-send the applicable agreements. Used after Add Service or when a client lost the original email. |
| **Cancel Order** | Cancel the whole order or one phase (**Cancel This Inspection**). Removing one ancillary uses the separate **Remove Ancillary** modal. Covered in [Managing orders](/1nspect/workflows/managing-orders). |
| **Mark as Paid** | Record a manual payment: Amount paid, Date paid and Payment method (Cash, Check, Zelle, Venmo or Offline Credit Card), confirmed with **Record Payment**. |
| **Mark as No Charge** | In the inspection's Quick Actions, on an unpaid inspection. Makes it $0 and paid, and voids any sent or signed agreement so you can send the $0 one. See [No charge (comped)](/1nspect/workflows/managing-orders#no-charge-comped). |
| **Issue Refund** | Refund some or all of a payment: through Stripe for a card payment, otherwise recorded. Appears once paid, and not on a comped inspection. See [Refunds](/1nspect/features/refunds). |
| **Reschedule** | Move an inspection to a new date and time. Moves the reminder and fires Inspection Rescheduled. |
| **Create Reinspection** | On the Overview tab for completed inspections. See [Reinspections](/1nspect/workflows/reinspections). |

## Communications tab

On a child inspection, the **Communications** tab shows each email with its per-recipient delivery status. It has **Fire Workflow Trigger** and **Send/Resend Contract Bundle** actions. There is no per-email resend.

If an email bounces, a **bounce banner** appears at the top of the page and you also get a bounce notice email. See [Resend email](/1nspect/features/resend-email).

## Haven toggle (per order)

If Haven is enabled at the tenant level (**Business Ops › Integrations**), a per-order **Send to Haven on publish** toggle appears on the **Inspection Details** tab. Defaults to on; uncheck for orders you don't want sent. See [Haven integration](/1nspect/features/haven-integration).
