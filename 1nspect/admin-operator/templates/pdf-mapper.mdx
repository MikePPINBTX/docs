PDF Mapper is a diagnostic view of how a template's schema maps to the printed PDF. If a section comes out blank, a photo lands on the wrong page, or a finding never appears, the Mapper tells you which schema element is bound to which printed zone so you can trace the problem.

## Where to find it

In the top bar, click **Templates** › the Templates list › the PDF Mapper link (or route `/templates`).

## When to open it

Most subscribers never need this page. Reach for it when:

- A section appears in the schema but not in the printed report
- A finding is captured but doesn't print on the client's PDF
- A photo attaches to the inspection but doesn't appear on the right page
- You're building a custom template and want to confirm your zones are wired up

## What it shows

For each page type in the template (preamble, section template, summary), the Mapper shows:

- The zones defined on that page
- The schema elements bound to each zone (which section, which subsection, which field)
- Any zone with no binding (empty on render)
- Any schema element with no destination zone (captured but never printed)

The mismatch rows are the ones to act on.

## Fixing a mismatch

Zone and binding changes happen in the [Visual Page Designer](/1nspect/admin-operator/templates/template-designer), not in the Mapper itself. The Mapper is read-only diagnostic; once you've identified the mismatch, open the designer to fix it.
