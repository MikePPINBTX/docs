Templates define the structure of your inspections and the shape of your reports. The Intelligence Hub holds the text libraries and reusable text fragments that templates draw on. Both live in the web admin, each under its own top-nav item.

## The two groups

| Group | Top-nav item | What's inside |
| --- | --- | --- |
| **Templates** | **Templates** | Universal Template Builder (list of templates), per-template Schema Editor, Visual Page Designer, Guided Layout, PDF form import, PDF Mapper |
| **Intelligence Hub** | **Narrative Management** (opens as Intelligence & Library Hub) | Narrative Library (collections and import), Supplemental Documents, AI Persona (Voice DNA), Option Lists, Reference Snippets |

## Templates

A template has a **schema** (the sections, subsections and fields that drive the mobile Capture screen) and a **layout** (how the schema prints on the final report). Covered in detail in:

- [Universal Template Builder](/1nspect/admin-operator/templates/template-builder) — the list page
- [Template schema editor](/1nspect/admin-operator/templates/template-editor) — sections, subsections, fields, smart equipment fields
- [Visual Page Designer](/1nspect/admin-operator/templates/template-designer) — how the schema prints
- [Import from your PDF form](/1nspect/admin-operator/templates/schema-upload-and-review)

## How they come together on an inspection

1. The template defines the sections and subsections the inspector moves through
2. The schema's fields are filled in on mobile (smart equipment fields compute as the inspector enters values)
3. The caption library feeds the Capture screen's caption autocomplete
4. The narrative library feeds AI Generate (and Smart Search) when drafting
5. Reference snippets attach curated reference text to findings as needed
6. Supplemental documents attach to the final report by rule
7. The layout (Visual Page Designer or Guided Layout) controls how the finished report prints
8. The Cover Designer (separate top-nav item) controls the cover page

## Minimum setup to run an inspection

- A template, Active
- At least one caption library and one narrative library associated with that template
- A Standard of Practice bound to the template

See [Build your inspection template](/1nspect/getting-started/build-your-first-template) in Start Here for the first-time path.
