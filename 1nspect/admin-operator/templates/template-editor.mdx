The template schema editor is where you shape what the inspector sees on the mobile Capture screen: the sections across the middle, the subsections underneath, and the fields each subsection carries. Template editing is **Professional and Team only**.

## Where to find it

**Templates** top-nav › **Universal Template Builder** › click the **Edit** icon on a template card. Edit opens an overview page with **Schema** and **Visual Designer** tabs. The field editor lives on the **Schema** page (`/templates/builder/[templateId]/schema`), not on the overview page. You can also reach it from the card's **Upload Schema** icon or from the overview's **View Full Schema** button.

## The hierarchy

Every template has a two-level hierarchy:

- **Sections** — major divisions of the inspection (Structural, Electrical, Plumbing, HVAC, Roofing)
- **Subsections** — individual inspection areas within a section (Foundations, Grading, Roof Covering)

Each subsection carries fields and findings.

## Adding to the schema

- **Add Section** (top of the editor) — adds a new section
- **Add Subsection** (inside a section) — adds a subsection under it
- **Add Field** (inside a subsection) — adds a field

Rename a section or subsection inline. Reorder with **Move up** and **Move down**. Remove with the delete icon.

## Fields

Each field has a **Data Format** that drives the input type on mobile:

| Data format | Mobile input | Use for |
| --- | --- | --- |
| Text | Free-form text input | Equipment serial, free notes |
| Number | Numeric keyboard with units | Supply/return temperatures, amperage, pressure |
| Date | Date picker | Manufacture date, install date |
| Select | Dropdown fed from an Option List | Equipment type, fuel source, cladding material |
| Checkbox | Single tick box | Yes / no items |
| Radio | Pick one of a short list | Mutually exclusive choices |
| Computed (Δ-T, age…) | Read-only, calculated from other fields | Temperature split, equipment age |
| Comment | Free-text comment | Extra remarks |
| Photo Placeholder | A slot for a required photo | Nameplate, panel interior |

For Select fields, the dropdown contents come from a reusable Option List managed in the Intelligence Hub. One list can feed many fields across many templates.

## Smart equipment fields (computed)

Pick **Computed (Δ-T, age…)** as the data format and the form opens an operand picker:

- A **compute operation**: Difference (A − B) or Age from year
- The **operands** (which other number or computed fields to use)

Common patterns:

| Computed field | Operands | Operation |
| --- | --- | --- |
| Cooling delta (Δ-T) | Return air temp − Supply air temp | Subtract |
| Equipment age | Current year − Manufacture year | Subtract |

### Advisory ranges

Set a **minimum** and **maximum** on any number or computed field. Each bound is either a literal value or taken from another field. Ranges are labelled **advisory — never auto-defect**: an out-of-range reading shows a badge and admin messages, but it never creates a deficiency automatically. See [Smart equipment fields](/1nspect/getting-started/smart-equipment-fields) for the Start Here walk-through.

## Multi-instance subsections

Some subsections hold several instances of the same equipment: two HVAC units, three water heaters, four exterior spigots. Mark a subsection **multi-instance** in its editor and the mobile Capture screen gets an instance switcher at the top of that subsection. Each instance has its own location and field values; findings are tagged to the right one.

## Required fields

Mark any field **Required**. Required fields show on the mobile Fields counter chip (📋 Fields · N of M) and block the mobile readiness check until filled in.

## Save

Save your schema changes on the Schema page. Past inspections keep the schema they were captured against.
