The Universal Template Builder is the Templates top-nav page: your list of templates with status badges and the two actions to add a new one.

## Where to find it

In the top bar, click **Templates** (third top-nav item). The page header reads **Universal Template Builder**.

## The two "add template" actions

Top-right of the page:

- **Initialize from SoP** — clones a platform library bundle (TREC, InterNACHI, Phase 1 Pre-Pour, Phase 2 Pre-Drywall) into a new template on your account. The clone comes with the sections, subsections, fields and rating scale that standard specifies.
- **Create Custom Template** — starts a blank template. Build the schema from scratch.

For most firms, Initialize from SoP is the right first move: start from a working standard, then tweak.

## Template cards

Every template on your account appears as a card. Each card shows:

| Element | What it is |
| --- | --- |
| Template name | What subscribers and clients see |
| Standard badge | The SoP this template follows (TREC, InterNACHI, Phase 1 Pre-Pour, Custom) |
| SoP identifier | The machine-readable SoP ID (e.g. `SoP: trec_7_6`) |
| Description | A short line about what this template is for |
| Version | The current version number (e.g. 7.6) |
| Active badge (green) | On when the template is available for new orders |
| Schema Linked badge (blue outlined) | On when the template is bound to a schema |
| Created by + date | Who created it and when |

## Per-card actions

A row of icon actions at the bottom of each card:

| Icon | Action |
| --- | --- |
| ✏️ Edit | Open the template in the Schema Editor |
| 🎨 Design | Open in the Visual Page Designer or Guided Layout |
| ⬆️ Upload | Replace the schema from a PDF form |
| 📋 Duplicate | Clone this template |
| 👁 View | Preview the template |
| 🗑 Delete | Remove the template (confirmation required) |

## Seeded templates for new subscribers

When you sign up and pick your inspection standard, 1nspecT seeds your account with the matching residential template plus the two phase templates:

| Template | When it's seeded |
| --- | --- |
| TREC 7-6 residential | You chose TREC at signup |
| InterNACHI residential | You chose InterNACHI (or anything other than TREC) at signup |
| Phase 1 Pre-Pour Foundation Inspection | Always seeded |
| Phase 2 Pre-Drywall Inspection | Always seeded |
