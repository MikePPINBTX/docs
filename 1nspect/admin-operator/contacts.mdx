Contacts is where every client and agent on your account lives. Clients and agents are created automatically when you create orders; the Contacts page is for searching, viewing history, and tracking the agents who refer business to you.

## Where to find it

**Contacts** top-nav item. Page header: `Contacts`. Subheader: _"Clients, buyer's agents, and listing agents, with inspection history and referral tracking."_

## Search

Search box at the top: `Search by name, email, or brokerage…`. Matches on all three.

## Three toggle filters

Toggle buttons at the top switch the list:

- **Clients (N)** — only clients
- **Buyer's Agents (N)** — only buyer's agents
- **Listing Agents (N)** — only listing agents

Each shows a count. Click a toggle to filter the list.

## Columns

Each contact row carries:

- Name
- Email
- Phone (if captured)
- Brokerage (for agents)
- Inspection count (how many of your inspections they're on)
- Last inspection date
- Status / activity indicator

Click a row to open the contact's detail with full inspection history and (for agents) referral metrics.

## Where contacts come from

- **Clients** are created automatically when an order is created with that client's email
- **Buyer's agents** are created when an order has a buyer's agent email
- **Listing agents** are created when an order includes the listing agent

Edits made on the contact (fix a typo in a name, update an email) push to every linked inspection where that contact is referenced.

## Agent referral tracking

For every agent, the Contacts page carries:

- Count of referred inspections
- Count of signed orders
- Close rate (signed / referred)
- Revenue from signed inspections
- Last referral date

The [Agent Referral Report](/1nspect/features/agent-referrals) rolls this up by time window.

## No manual add today

There is no manual "Add Contact" action on this page. Contacts are created from orders only. Adding a CSV import or a direct Add Contact action is on the roadmap.
