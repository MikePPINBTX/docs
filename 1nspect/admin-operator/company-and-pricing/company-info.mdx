Company Info is the first tab of Business Ops. It carries the company-wide values the rest of 1nspecT reads: identity, brand colors, logo, inspection defaults, mobile settings, booking link and review links.

## Where to find it

**Business Ops** top-nav › **Company Info** tab (first of seven tabs).

## Fields

| Field | Notes |
|---|---|
| Account ID | Your account identifier. Read-only reference. |
| Company Name | Required. Appears on reports, emails, agreements, portals and invoices. |
| Company Phone | Your company phone number. |
| Office Address | Street, City, State, ZIP. Used only as the **fallback** for mileage surcharges: the inspector's home address is used first, and public bookings use the office address. |
| Support Email | Appears on client-facing notifications. |
| Brand Colors | **Primary**, **Secondary** and **Accent**. (There is no PWA theme color.) |
| Logo URL | A URL field, not an upload. Paste a link to your hosted logo. To upload a logo file, use Settings › Company. |
| Inspection Defaults | Company defaults for the narrative and caption libraries on new inspections. Libraries are then set per inspection on Inspection Details. |
| White-Label | Checkbox that changes only the web admin's own top bar. It does not affect PDFs, emails, agreements or the portals. See [Branding](/1nspect/getting-started/branding). |
| Dynamic Rating UI | Company setting for how ratings are presented. |
| Allow Publishing Reports from Mobile | Company switch, **off by default**. When on, users can publish from the mobile Review screen unless opted out per user in Settings › Users. |
| Save Inspection Photos to Inspectors' Camera Rolls | Saves captured photos to each inspector's phone camera roll. Off by default. |
| Booking Page Slug | The slug for your public booking page (`app.1nspect.app/book/[slug]`). |
| Google Review Link | Direct link to leave a Google review. Feeds `$GoogleReviewLink`. |
| Yelp Review Link | Direct link to leave a Yelp review. Feeds `$YelpLink`. |

<Note>
  There is no company-wide Google Calendar setting. The old "Primary Booking Calendar" box was removed. Calendars are connected per inspector in Settings › Users. See [Google Calendar](/1nspect/features/calendar-integration).
</Note>
