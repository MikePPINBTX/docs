Company Info is the first tab of Business Ops. It carries the company-wide identity values the rest of 1nspecT reads: name, address, support email, logo, booking link, review links, and the PWA theme color.

## Where to find it

**Business Ops** top-nav › **Company Info** tab (first of seven tabs).

## Fields

| Field | Notes |
|---|---|
| Company Name | Required. Appears on reports, emails, agreements, portals, invoices. Placeholder: `Your Company Name`. |
| Office Address | Street, City, State, ZIP. Used for mileage surcharge calculation. |
| Support Email | Appears on client-facing notifications. Placeholder: `support@yourcompany.com`. |
| Logo | PNG or SVG, recommended 200×50px. Also used as the PWA icon when installed on mobile devices. |
| PWA Theme Color | Status bar color when PWA is installed on mobile devices. Placeholder: `#1e40af`. |
| Google Review Link | Direct link to leave a Google review for your company. Feeds `$GoogleReviewLink`. |
| Yelp Review Link | Direct link to leave a Yelp review. Feeds `$YelpLink`. |
| Booking Slug | The slug for your public booking page (`app.1nspect.app/book/[slug]`). |
| Primary Booking Calendar | Google Calendar connection (fallback when per-inspector calendars aren't set). |

## Save

**Save Company Info** at the bottom.

## PWA (installable mobile web app)

1nspecT's web admin can be installed as a Progressive Web App on an inspector's or admin's mobile device. The logo you upload here is the PWA icon shown on the home screen; the PWA theme color is the status bar color. Install from your mobile browser's "Add to Home Screen" action.
