The 1nspecT web admin is where you set up and run the business. Ten items along the top navigation; a user chip, Help button, Branding palette, and Logout along the right. This page is the map.

## Top navigation (left to right)

| Item | What's inside |
| --- | --- |
| [**Dashboard**](/1nspect/features/dashboard-overview) | KPI tiles, charts, business insights, upcoming inspections, top agents |
| [**Inspections**](/1nspect/admin-operator/inspections-list) | Every order and quote. Opens the Order Creation Wizard and per-order Inspection Details. |
| [**Templates**](/1nspect/admin-operator/templates/template-builder) | Universal Template Builder, schema editor, Guided Layout, Visual Page Designer |
| [**SoP Manager**](/1nspect/admin-operator/sop-manager) | Browse standards of practice, clone to customize |
| [**Narrative Management**](/1nspect/admin-operator/intelligence-hub/overview) | Intelligence & Library Hub (Narrative Library, Supplemental Documents, Voice DNA, Option Lists, Reference Snippets) |
| [**Contacts**](/1nspect/admin-operator/contacts) | Clients, buyer's agents, listing agents with inspection history |
| [**Cover Designer**](/1nspect/admin-operator/cover-designer) | Build branded report cover pages |
| [**Reports**](/1nspect/features/reports-overview) | Nine business reports: Monthly Reconciliation, Stripe Payouts, All Invoices, Outstanding A/R, Service Mix, Agent Referrals, Inspector Productivity, Activity Log, Tax Summary |
| [**Business Ops**](/1nspect/admin-operator/company-and-pricing/company-settings) | Seven tabs: Company Info, Pricing, Payments, Contracts, Communications, Quotes, Integrations |
| **Settings** | Branding (color scheme, preset themes, embed, white label) and Users |

Owner-only extra after the ten standard items: **Platform Admin** (purple border, for MAVTech operations, not relevant to subscribers).

## Right-side header actions

- Your display name (first and last) with a role chip (owner / admin / inspector)
- **Help** (HelpCircle icon) — opens this help site in a new tab
- **Branding & Settings** (Palette icon) — jumps to `/settings`
- **Logout** (LogOut icon, hover-red)

## Phone view

Below 768px wide, the ten top-nav items collapse into a hamburger drawer along with Platform Admin (owner only), User Guide and Logout. The user menu moves into the drawer header.

## Billing lives under Settings

Billing is at `/settings/billing`, not under Business Ops. See [AI Credits](/1nspect/features/it-tokens) and the Billing section of your Settings page.
