Contracts Cockpit is the Business Ops tab where you build the service agreements clients sign. 1nspecT's e-signature is built in: clients sign in a browser from their portal and the signed PDF is stamped and stored on the order.

## Where to find it

**Business Ops** top-nav › the **Contracts** tab (fourth of seven tabs). Section inside is labeled **Agreements**.

## Agreement editor

Covered in detail in [Contract templates](/1nspect/getting-started/contracts) and [Variable tags reference](/1nspect/getting-started/variable-tags-reference).

Each agreement captures:

- **Agreement name** — placeholder `Agreement name (e.g. Primary Service Agreement)`
- **Send this agreement when** — the trigger
- **Agreement Body** — rich-text with **Insert Tag** dropdown
- **Save Agreement** at the bottom
- **Test Send** — expands a panel with an Inspection ID input (placeholder `Inspection ID (e.g. 2026-0062-RS)`) and a **Send** action that sends every applicable agreement for that inspection in test mode

## Insert Tag groups

- Contract Date
- Client
- Co-Client
- Address
- Service
- Scheduling
- Pricing
- Signature - Client (`[[sig|req|signer1]]`)
- Signature - Co-Client (`[[sig|req|signer2]]`)
- Company (`$CompanyName`, `$CompanyLogo`)

See [Variable tags reference](/1nspect/getting-started/variable-tags-reference) for the full catalog.

## Multiple agreements

A tenant can have multiple agreements, each scoped to the orders it applies to:

- A primary service agreement that applies to All orders
- A reinspection agreement that applies to Reinspections only
- An ancillary-specific agreement (if that ancillary has Own Agreement turned on in Pricing Manager)

1nspecT bundles the applicable agreements at send time via **Resend Bundle** on each order.

## Deleting an agreement

Click the delete action on the agreement card. Confirmation: `Delete this agreement? This cannot be undone.`
