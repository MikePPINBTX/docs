Cover Designer builds the branded cover page that opens every PDF report. Each template can carry its own cover design; most firms build one for their resale template and reuse it for the phase inspection templates.

## Where to find it

**Cover Designer** top-nav item. Page header reads **Cover Templates**.

## The Cover Templates list

Every cover template on your account appears as a card. Empty state shows: _"Create your first cover template to add branded cover pages to reports."_

Top-right action: **New Cover Template**. Empty-state users see a centered **Create First Template** button.

## The Cover Designer editor

Clicking into a cover template opens the editor. Three panels:

- **Left**: component library (frames, text blocks, hero blocks, static text, images)
- **Center**: the canvas, laid out at report dimensions
- **Right**: Layer Panel (drag to reorder) + Properties Panel for the selected layer

The template name input at the top has placeholder `Cover template name`. Save with the **Save** action at the top right.

## Layer types

| Layer | What it is |
| --- | --- |
| Frame image | A full-canvas background image. No geometry controls - always spans the canvas. |
| Hero block | A large text block for the headline (property address, inspection date) |
| Text block | Any text with dynamic field tokens pulled from the order at render time |
| Static text | Fixed text that doesn't change per report |
| Group block | A grouped set of elements that move together |

## Dynamic tokens

Text layers can carry tokens that fill in at render time:

- Property address
- Client name(s)
- Inspection date
- Inspector name
- Company name
- Company logo

Tokens render per-report so your cover auto-populates for every inspection using this template.

## Assigning a cover to a template

The cover is bound to the template on the template card in the Universal Template Builder. One template, one cover. For firms with different brands per service, build one cover per template.
