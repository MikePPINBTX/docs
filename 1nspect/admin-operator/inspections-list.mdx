The Inspections list is the master view of every order and quote on your account. Open the top-nav **Inspections** item to land here. Dashboard action-item tiles deep-link into this page with filters pre-applied.

## Where to find it

**Inspections** top-nav. Page header: `Inspections`.

## Search

A search box at the top: `Search by client name(s) or address…`. Matches against primary client, co-client and property address.

## Status filter

Dropdown of statuses, plus one synthetic filter:

- **All** (default)
- **Scheduled**, **Assigned**, **In Progress**, **Completed**, **Cancelled** (actual statuses)
- **Unsigned contract** — synthetic, client-side filter: orders where at least one phase still has an unsigned active agreement

## URL seeding

The status filter can be pre-set from the URL (`?status=unsigned`). Dashboard tiles like "N unsigned agreements" deep-link here so the list matches the tile count.

## Columns

Each row shows:

- Client Name
- Address
- Scheduled Date
- Inspector / Services
- Status
- Actions

Click any row to open [Inspection Details](/1nspect/admin-operator/inspection-details).

## Add a new order

Top right of the page: the **Create Inspection** button opens the [Order Creation Wizard](/1nspect/admin-operator/order-creation-wizard). An **Inspections / Quotes** toggle switches the list between orders and quote leads.
