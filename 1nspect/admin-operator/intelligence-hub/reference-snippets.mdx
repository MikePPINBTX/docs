Reference Snippets are short citations or links your inspectors can attach to findings on the Capture screen: recurring code citations, manufacturer references, safety advisories. A snippet is a short label, not a rich body of text.

## Where to find it

**Narrative Management** top-nav › **Intelligence & Library Hub** › the **Reference Snippets** tab (fifth tab).

## What a snippet is

A short label, with an optional link and a scope, that an inspector picks from the mobile Capture screen's snippets picker and attaches to a finding. The label prints alongside the narrative in the published report.

## Fields per snippet

| Field | Notes |
| --- | --- |
| Label | Up to 200 characters. Shown in the picker and printed in the report |
| URL | Optional, https only |
| Scope | Template + subsection pairs where the snippet is available. An empty scope means nowhere; there is no "all templates" option |
| Material triggers | Optional triggers tied to materials |

There is no Source field, no rich body and no Active toggle.

## Adding a snippet

<Steps>
<Step title="Click add">
From the Reference Snippets tab.
</Step>
<Step title="Write the label">
Short and descriptive (200 characters at most). Inspectors see it in the picker and clients see it in the report. Add a URL if you want to link out.
</Step>
<Step title="Set the scope">
Add template + subsection pairs. Inspectors only see snippets whose scope matches the finding they're on. An empty scope makes the snippet available nowhere.
</Step>
<Step title="Save">
The snippet is available in the mobile picker after the next sync.
</Step>
</Steps>

## On the Capture screen

For findings in-scope, the mobile Capture screen shows a snippets picker alongside the narrative tools. Inspectors tap a snippet to attach it. One finding can carry several snippets. Attached snippet labels print alongside the narrative on the published report.

## When to use snippets vs. narratives vs. AIPI

| Use a... | When... |
| --- | --- |
| **Narrative** | The content is a per-finding wording of a deficiency or observation |
| **Reference snippet** | The content is a short citation or link that attaches to specific findings |
| **AIPI** | The content applies to the whole report (installer qualifications, scope caveats, limitations) |
| **Supplemental document** | The content is a full PDF offered as a download in the client portal |

## Removing a snippet

Delete removes the snippet from the picker. Past reports with the snippet attached keep the content; new inspections no longer see it.
