Open any collection from the Narrative Library tab to see every caption and narrative it contains, filter by type, edit entries, add new ones, and work through duplicates. AIPI is not on this page; it is managed from the narrative-library cards.

## Where to find it

**Narrative Management** top-nav › **Intelligence & Library Hub** › **Narrative Library** tab › click a collection card.

The page header is the collection name.

## Top-right actions

- **Add Narrative** — opens the editor to add a new narrative or caption

## Filters

The Filters panel on the left narrows the list:

- **Type** — All, Photo Captions, Deficiency Comments, Report Area Comments
- **Section** — the inspection section the entry is tagged to
- **Report Area** — the report area the entry is tagged to
- **Search** — matches against the narrative or caption text

There is no status filter.

## The entries list

The main panel shows each matching entry with:

- The caption or narrative text
- Its type badge (Photo Caption or Deficiency Comment)
- The section and subsection it's tagged to
- Edit and Delete actions per row

Click **Add Narrative** at the top right to add a new entry. The editor captures the text, the type, the section and the report area. There is no severity field.

## Duplicate finder

Click **🔍 Show Duplicates (N)** to see the entries in this collection that repeat each other. A line at the top counts them, for example _"3 duplicate groups • 5 redundant entries"_. Click **← Back to all narratives** to return to the full list. If there are none, the page says _"No duplicates found"_.

It checks the whole collection, whatever filter you have on, so it also finds the same caption filed under two different subsections. Captions and deficiency comments are never grouped with each other.

Each group is a card headed **identical entries** or **similar entries**:

- **Identical:** the same text, apart from capitals and spacing.
- **Similar:** the same words, apart from punctuation, word order, singular or plural, hyphens and small words such as "a", "the", "of" or "and". "Not", "no" and numbers always count, so "installed" and "not installed" are never grouped. Wording that adds or drops a real word isn't grouped either. For example, "Cracked and spalling parge coat" and "Spalling parge coat" stay separate.

Each row shows how many times the entry has been used, its section and subsection. Click **Keep this one** on the version you want, and confirm, to delete the others in the group. Nothing is merged into the entry you keep.

## AIPI (Additional Information Provided by Inspector)

Each narrative-library collection carries up to two AIPI blocks, one for standard reports and one for reinspection reports. They are opened from the buttons on the collection's card in the Narrative Library (not from this page), and are not available for caption libraries. The AIPI editor is a rich-text dialog with headings, bold, italics, lists and links.

| Variant | Prints on |
| --- | --- |
| **Standard AIPI** | Reports that use this collection, when the inspection type has no Standard text of its own |
| **Reinspection AIPI** | Reinspection reports that use this collection, when the inspection type has no Reinspection text of its own |

The collection's AIPI is the fallback. Text written for an inspection type in the **Limitations Text (AIPI)** tab prints first. See [AIPI](/1nspect/getting-started/aipi#which-text-prints) for the full order, when to use each and how to word them.
