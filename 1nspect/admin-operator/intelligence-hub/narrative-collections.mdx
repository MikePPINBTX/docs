Open any collection from the Narrative Library tab to see every caption and narrative it contains, filter by type, edit entries, add new ones, and work through duplicates. AIPI is not on this page; it is managed from the narrative-library cards.

## Where to find it

**Narrative Management** top-nav › **Intelligence & Library Hub** › **Narrative Library** tab › click a collection card.

The page header is the collection name.

## Top-right actions

- **Add Narrative** — opens the editor to add a new narrative or caption

## Filters

The Filters panel on the left narrows the list:

- **Type** — All, Photo Captions, Deficiency Comments, Report Area Comments
- **Section** — the inspection section the entry is tagged to
- **Report Area** — the report area the entry is tagged to
- **Search** — matches against the narrative or caption text

There is no status filter.

## The entries list

The main panel shows each matching entry with:

- The caption or narrative text
- Its type badge (Photo Caption or Deficiency Comment)
- The section and subsection it's tagged to
- Edit and Delete actions per row

Click **Add Narrative** at the top right to add a new entry. The editor captures the text, the type, the section and the report area. There is no severity field.

## Duplicate finder

A **🔍 Show Duplicates (N)** toggle filters the list to entries that look like duplicates (same caption with slightly different wording, same narrative text re-saved). Work through them to consolidate: pick the canonical version and delete the others.

## AIPI (Additional Information Provided by Inspector)

Each narrative-library collection carries up to two AIPI blocks, one for standard reports and one for reinspection reports. They are opened from the buttons on the collection's card in the Narrative Library (not from this page), and are not available for caption libraries. The AIPI editor is a rich-text dialog with headings, bold, italics, lists and links.

| Variant | Prints on |
| --- | --- |
| **Standard AIPI** | Every published report that uses this collection |
| **Reinspection AIPI** | Reinspection reports only, in place of the standard AIPI |

See [AIPI](/1nspect/getting-started/aipi) for when to use each and how to word them.

## Firebase connection check

If the collection view fails to load with _"Firebase Connection Required"_, the admin cannot reach the data store. Refresh the page; if the error persists, email `support@mymavtech.com`.
