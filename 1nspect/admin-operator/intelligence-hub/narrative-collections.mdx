Open any collection from the Narrative Library tab to see every caption and narrative it contains, filter by type, edit entries, add new ones, work through duplicates, and attach the AIPI (if your SoP allows).

## Where to find it

**Narrative Management** top-nav › **Intelligence & Library Hub** › **Narrative Library** tab › click a collection card.

The page header is the collection name.

## Top-right actions

- **Add Narrative** — opens the editor to add a new narrative or caption
- **AIPI** actions — add or edit the standard AIPI and the reinspection AIPI for this collection

## Filters

The Filters panel on the left narrows the list:

- **Type** — All, Photo Captions, Deficiency Comments
- **Section** — the inspection section the entry is tagged to
- **Status** — Active, Draft, Archived
- **Text search** — matches against the narrative or caption text

## The entries list

The main panel shows each matching entry with:

- The caption or narrative text
- Its type badge (Photo Caption or Deficiency Comment)
- The section and subsection it's tagged to
- Edit and Delete actions per row

Click **Add Narrative** at the top right to add a new entry. The editor captures the text, the type, the section, and optional metadata (deficiency flag, severity).

## Duplicate finder

A **Duplicates** view groups entries that look similar enough to be duplicates (same caption with slightly different wording, same narrative text re-saved). Work through the duplicates view to consolidate: pick the canonical version and delete or merge the others.

If there are no duplicates to clean up, the view shows: _"No duplicates found."_

## AIPI (Additional Information Provided by Inspector)

Each collection carries up to two AIPI blocks, one for standard reports and one for reinspection reports. The AIPI editor is a rich-text dialog with headings, bold, italics, lists and links.

| Variant | Prints on |
| --- | --- |
| **Standard AIPI** | Every published report that uses this collection |
| **Reinspection AIPI** | Reinspection reports only, in place of the standard AIPI |

See [AIPI](/1nspect/getting-started/aipi) for when to use each and how to word them.

## Firebase connection check

If the collection view fails to load with _"Firebase Connection Required"_, the admin cannot reach the data store. Refresh the page; if the error persists, email `support@mymavtech.com`.
