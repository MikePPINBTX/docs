Option Lists are reusable pick lists that feed template Select fields across every template on your account. One list, many fields across many templates. Edit the list and the change propagates to every template field bound to it.

## Where to find it

**Narrative Management** top-nav › **Intelligence & Library Hub** › the **Option Lists** tab (fourth tab). Or at `/option-lists` directly.

## The lists view

The page shows every option list on your account as a card:

| Element | What it is |
| --- | --- |
| Name | The list name (e.g. `Foundation Types`, `Cladding Materials`, `Roof Covering`) |
| Option count | How many options the list carries |
| Where it's used | Count of fields across templates that bind to this list |

## Add a new list

Click **Create Option List** (or **Create Option List** in the empty state when no lists exist). The editor dialog opens with the title **Create Option List**. Capture:

- List name
- The options themselves (one per line, each with an optional display label)
- Default option (if applicable)

Save to add.

## Edit a list

Click a list card to open the edit dialog (title **Edit Option List**). The same fields as the create dialog. Save to update.

## Propagation

When you add, remove or rename an option in a list, the change propagates to:

- Every template field bound to the list (dropdown options update)
- Every mobile Capture screen rendering those fields
- The next published report (past reports show the historical values they were captured with)

## Deleting a list

Delete a list only if no template field binds to it (otherwise those fields lose their options). The UI warns if you try to delete a list that's in use.
