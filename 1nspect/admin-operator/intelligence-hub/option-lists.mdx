Option Lists are reusable pick lists that feed template Select fields across every template on your account. One list, many fields across many templates. Edit the list and, after you confirm, the change reaches the template fields bound to it.

## Where to find it

**Narrative Management** top-nav › **Intelligence & Library Hub** › the **Option Lists** tab (fourth tab). The standalone `/option-lists` page is a dead page over a decommissioned service; use the tab.

## The lists view

The page shows every option list on your account as a card:

| Element | What it is |
| --- | --- |
| Name | The list name (e.g. `Foundation Types`, `Cladding Materials`, `Roof Covering`) |
| Option count | How many options the list carries |
| Where it's used | Count of fields across templates that bind to this list |

## Add a new list

Click **New List**. Capture:

- **Name**
- **Description**
- The ordered values

There are no display labels and no default option. Save to add.

## Edit a list

Click a list card to open the edit dialog (title **Edit Option List**). The same fields as the create dialog. Save to update.

## Propagation

When you change a list, the admin must confirm **Update N fields** before it reaches the bound template fields. The change then reaches:

- New inspections
- The next Push to Mobile

Inspections already started keep a **frozen copy** of the list and do not change. Past reports keep the values they were captured with.

## Archiving a list

Lists are **archived**, not deleted. Archive a list you no longer need; fields already bound to it keep their options.
