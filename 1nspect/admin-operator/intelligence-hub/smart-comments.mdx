Smart Comments are reusable, parameterized comment fragments you can drop into template authoring or report editing. The Smart Comments page lets you build, preview, and manage them, along with color schemes and report templates that affect how they render.

## Where to find it

Direct route: `/smart-comments`. Also reachable from the Intelligence & Library Hub navigation. The page header reads **Smart Comments**.

## What's on the page

The page has several panels:

- **Keyword Management** — surfaced here as a related section (also a standalone tool, see [Keyword Management](/1nspect/admin-operator/intelligence-hub/keyword-management))
- **Smart Comments Settings** — color schemes, report templates, integration settings
- **Report Content Preview** — a live preview of how your comments will render in a published report
- **Report Preview** — a wider preview of the final report with your comment choices applied

## Color schemes

Multiple color schemes are available. Each scheme sets the colors used for ratings, section headers, flagged items and background panels in the report preview. Pick the one you want to standardize on.

## Report templates

Several report templates ship with your account:

- **Standard Inspection Report** — the default layout for most inspections
- **Quick Assessment** — a shorter layout for lightweight inspections

The chosen report template affects how Smart Comments render on the final report.

## Integration settings

Settings that affect how Smart Comments integrate with other parts of the product.
