The Narrative Library is the first tab of the Intelligence & Library Hub. It holds every caption and narrative collection on your account, lets you associate a collection with a template, and imports existing libraries from XML.

## Where to find it

**Narrative Management** top-nav › **Intelligence & Library Hub** › the **Narrative Library** tab (first tab).

## Two sub-tabs

Inside the Narrative Library tab:

- **Collections** — the list of your collections, with the Associate-Template picker and per-collection actions
- **Import** — bring in an existing library from XML

## Collections list

Each collection card shows:

| Field | What it is |
| --- | --- |
| Name | What subscribers see |
| Narrative count | How many narratives in the collection |
| Caption count | How many captions |
| Deficiency count | Narratives tagged as deficiencies |

Click a card to open [Collection Detail](/1nspect/admin-operator/intelligence-hub/narrative-collections) for the full set of captions and narratives.

## AIPI buttons on the cards

The AIPI actions live on the **narrative-library cards** on this page: **Add/Edit Additional Information** and **Add/Edit Reinspection Additional Information**, with a check mark once configured. They are not available on caption library cards. See [AIPI](/1nspect/getting-started/aipi).

## Associate with a template

Each collection has an **Associate Template** picker. The association is only a **fallback**: libraries are actually chosen **per inspection** on Inspection Details, with company defaults in Business Ops › Company Info › Inspection Defaults.

<Tip>
  One template can carry more than one collection of each type. A single TREC template can serve a 2026 new build and a 1920s craftsman home, each with its own deficiency language. You pick which collection applies per inspection, on Inspection Details.
</Tip>

## Collection types

A collection is either a caption library (`caption_library`) or a narrative library (`narrative_library`). There is no "both". The data type separation shows up in the Collection Detail filter:

- **Photo Captions** — the short captions that feed the mobile Capture screen autocomplete
- **Deficiency Comments** — the full narratives that feed AI Generate and Smart Search

## Import

The second sub-tab imports an existing library from XML. Supported formats:

- **HomeInspectorPro XML** export
- Generic XML conforming to 1nspecT's import schema

Drop the file, the import wizard reads it, maps sections against your templates, and brings the content into a new collection you can then associate with the right template.

<Note>
  CSV and Excel import are not supported today. Only XML works.
</Note>

## Add a collection

Add action in the Collections tab. Pick the type (caption or narrative) and give it a name. Open the new collection to add entries one at a time, or import from XML.
