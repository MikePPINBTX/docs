Your company profile is the foundation that the rest of 1nspecT builds on. The name you set here goes on every report, email, agreement and portal page the client sees. (White-label mode, by contrast, changes only the web admin's own top bar.) Set it up before you touch any other section.

<Info>
  **Required** to run your first inspection: Company name.
</Info>

## Where to find it

In the web admin top bar, open **Business Ops**. You land on the **Company Info** tab (the first tab across the top of the Business Operations page). The page header reads **Business Operations**.

## Fields to set

| Field | Notes |
| --- | --- |
| Company name | Required. Appears on reports, emails, agreements, portals, invoices. |
| Office address | Street address, City, State, ZIP. Only the **fallback** for mileage surcharges: the inspector's home address is used first, and public bookings use the office address. |
| Support email | Appears on client-facing notifications and portal pages. |

The same page has more fields you can set now or later: Account ID, Company Phone, Company Logo, Brand Colors (Primary, Secondary, Accent) and preset themes, Installed App Status-Bar Color, Inspection Defaults, Enable White-Label Mode, Dynamic Rating UI, Allow Publishing Reports from Mobile, Save Inspection Photos to Inspectors' Camera Rolls, Booking Page Slug, the Public Booking Form, and your Google and Yelp review links. See [Company Info](/1nspect/admin-operator/company-and-pricing/company-info) for each one.

<Note>
  Business Ops › Company Info is the only place these fields are edited. The old Settings page is gone; links to `/settings` now open Company Info.
</Note>

<Tip>
  Use a monitored inbox for the support email. This address appears on client-facing notifications. Workflow emails have no reply-to, so replies do not automatically land in this inbox; make sure clients can reach someone through it.
</Tip>

## Save

At the bottom of the Company Info tab, click **Save Changes**. A browser alert confirms "Company profile saved successfully".
