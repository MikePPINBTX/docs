Many properties have a separate garage, workshop, guest house or barn that the client wants inspected along with the main home. 1nspecT handles these as **detached structures**: separate billable items set up once as sq-ft-priced ancillary services, then added row by row on each order where they apply.

<Info>
New subscribers get two detached-structure services seeded on their account as placeholders. You can edit, rename, or delete them.
</Info>

## How detached structures are priced

Under the hood, a detached structure is a **sq-ft-priced ancillary service** with the **Structural** category. One structure = one fee line on the order. The fee scales with the structure's square footage using the sqft tiers you set on the ancillary, exactly like a primary service does.

Because each structure is billed per square footage, the Base Fee and the New Construction overrides from a regular ancillary do not apply. Instead you set a sqft-tier table for the structure.

## Setting up a structure type

One-time setup, done on the Ancillary Services tab:

<Steps>
<Step title="Open Pricing Manager">
Business Ops › Pricing, then the Ancillary Services tab.
</Step>
<Step title="Add or edit a Structural ancillary">
Tick **Priced by square footage**. This checkbox, not the Category, is what enables sqft pricing (Structural is a sensible Category). Give it a descriptive name (e.g. `Detached Garage`, `Workshop`, `Guest House`, `Barn`).
</Step>
<Step title="Define the sqft tiers">
On the per-structure sqft table, add a row per tier, either a flat fee or a per-sq-ft rate. Tiers are **first-match**: 1nspecT uses the first tier the square footage falls in, with **no interpolation** between tiers.
</Step>
<Step title="Fill the rest of the ancillary fields">
Duration per minute, Taxable, Pass-Through, Revenue Model as usual.
</Step>
<Step title="Save">
Click Save Fees & Surcharges. It commits with the rest of the Ancillary / Packages / Discounts / Surcharges / Settings changes.
</Step>
</Steps>

## Adding structures on an order

On the Order Creation Wizard and the Edit Order modal, the wizard section is titled **Detached Structures** (Residential only) and shows an **Add structure** row list. For each row you pick:

- **Label**: a name for this structure
- **Type**: the detached-structure ancillary (one of the ones you set up above)
- **Sqft**: the square footage of that structure

1nspecT reads the sqft tiers you set up for that type, calculates the fee for the entered sqft, and adds a line to the order. It also rolls the structure's duration (in minutes) into the on-site time estimate.

Add as many rows as there are structures on the property. Remove a row to drop that structure (and its fee and duration) from the order.

## When structures are included vs. extra

Structures are **always billed in addition** to the primary inspection. There is no package or discount that merges them into the main service price. If you want a bundle (for example, a large-home package that includes a garage inspection), build it under Packages and add the structure ancillary as a package line with a discount.
