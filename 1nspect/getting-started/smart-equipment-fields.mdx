On your template's Schema page, you can add fields that go beyond simple text and numbers. **Smart equipment fields** capture readings in the right units, compute values from other fields (temperature rise, equipment age), and flag out-of-range readings automatically in the field before the inspector moves to the next room.

## Where to add them

Open the template in **Templates** (top nav), click the **Edit** icon, then open the **Schema** page (the field editor lives there, not on the overview page) and the subsection you want to add a field to. The field form opens. The key field is **Data Format**:

| Data format | Use for | Example |
| --- | --- | --- |
| Text | Any free-form text | Equipment serial number |
| Number | A numeric reading | Supply air temperature, amperage draw |
| Date | A date | Equipment manufacture date, installation date |
| Select | A choice from a dropdown | Equipment type, fuel source |
| Computed (Δ-T, age…) | A value derived from other fields | Temperature split, equipment age |

Checkbox, Radio, Comment and Photo Placeholder are not data formats; they are options on the separate **Field Type** menu. This is a Professional and Team feature.

## Computed fields

Select **Computed (Δ-T, age…)** as the data format, and the form opens up an operand picker. Pick:

- **A compute operation**: two are offered, **Difference (A − B)** and **Age from year**
- **The operands** (which other numeric or computed fields to use)

### Typical examples

| Field | Operands | Operation |
| --- | --- | --- |
| Supply/return temperature split (Δ-T) | Supply Air Temperature − Return Air Temperature | Difference (A − B) |
| Cooling delta | Return Air Temperature − Supply Air Temperature | Difference (A − B) |
| Equipment age | Manufacture Year | Age from year |

Computed fields update live as the inspector enters the operand values on mobile. Nothing to tap, no need to type the result.

## Advisory ranges

On any number or computed field, you can set an **advisory range**: an expected minimum and maximum. Ranges are labelled **advisory — never auto-defect**. When the captured value falls outside the range, 1nspecT shows a badge and a suggestion, but it does **not** automatically draft a deficiency.

### Where ranges come from

Each bound (min and max) is set one of two ways:

1. **Literal** — a value you type
2. **From field** — taken from another field on the form

There are no manufacturer or SoP sources.

### What happens on mobile

An out-of-range value shows a badge and a suggestion. The inspector decides whether to write a deficiency; the AI never creates one on its own. The inspector still approves every word. See [AI features](/1nspect/features/ai-features) for the full narrative-drafting flow.

## Where to start

A great first smart field for most companies is a **furnace temperature-rise check**: supply air temperature, return air temperature, computed difference, advisory range set from the manufacturer's rating plate (typed in as literal values). Your onboarding specialist can help you set up a few of these.
